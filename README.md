# Operation: Please Forgive Me, Tahreem ❤️

A self-contained interactive apology website.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. On the final screen, choose your MP3 file to add your song.
4. Share the folder by deploying it to a static host (for example GitHub Pages, Netlify, or Vercel).

## Notes
- No build step or dependencies are required.
- Cartoon slap and click sounds are synthesized in the browser.
- Audio starts only after the visitor presses play.
- The selected song stays local to that browser session; it is not uploaded anywhere.
- Internet is only needed for the optional Google Fonts import. The website otherwise works offline.
